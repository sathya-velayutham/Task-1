# CREATE A TABLE USING HTML
  This is a simple HTML Project created to display student details in a table format.

# TECHNOLOGY USED
   HTML

# TABLE HEADINGS
   1. Roll Number
   2. Student Name
   3. Major
   4. Department
   5. CGPA

# FEATURES
   Displays 10 Students Details.
   Uses HTML Table tags.
   include table heading and borders.

# HTML TAGS USED
  <table> </table>   ---->  To Create a Table
     <tr> </tr>      ----> To Create Table Rows
     <th> </th>      ----> To Create Table Headings
     <td> </td>      ----> To Create Table Data's
